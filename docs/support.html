Mic Pause Support

Apple Music is not pausing

Open Mic Pause Settings and confirm that monitoring is enabled and Apple Music Automation says Allowed. If it is denied, enable Mic Pause under System Settings → Privacy & Security → Automation.

The microphone always appears active

Mic Pause reports the device-level Core Audio running state. Some audio drivers keep the input device running even when an app is not recording. Quitting the app that owns the input or selecting another default input device may resolve this.

Music should not resume

Turn off Resume Apple Music automatically in Mic Pause Settings. Mic Pause resumes only pauses that it initiated.
